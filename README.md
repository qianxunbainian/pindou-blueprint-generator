# 拼豆图纸工坊

照片转 MARD 拼豆图纸：真实色号、照着瓶身就能拼。全程在浏览器本地运行，照片不上传。

在线使用：https://qianxunbainian.github.io/pindou-blueprint-generator/

## 功能
- **真实色卡**：MARD 221 色 / 185 色两套可切换，色号就是瓶身上印的 A1 / F3 / H7……（色卡 RGB 取自 bitbead.app 开放数据集，CC BY 4.0，与公开色卡交叉核对）
- **感知配色**：在 Lab 色彩空间按人眼感知匹配最近色，再按用量收敛到设定的颜色上限；可选 Floyd–Steinberg 抖动，渐变与肤色更自然
- **贴合拼豆板**：宽度预设 29 / 58 / 87 格（一块 / 两块 / 三块标准板），图纸上每 29 格有红色板线，带行列坐标
- **裁剪与调图**：缩放、移动取景；亮度 / 对比度 / 饱和度；「只用我已有的色号」限制色卡；自动清理孤点杂色
- **四种显示**：颜色+色号 / 纯颜色 / 纯色号 / 符号（黑白打印用）
- **改色编辑**：点格改色、橡皮擦、撤销；点清单中的颜色可高亮定位
- **拼制模式**：边拼边勾，进度保存在本地；完成打勾显示
- **导出**：带坐标、板线、图例的高清 PNG（可镜像，方便熨烫）、用豆清单 CSV、一键复制购物清单（色号 × 颗数，含每 1000 颗一包的袋数估算）

## 使用
浏览器打开 `index.html` 即可，无需服务器、无需联网。内置一幅 29×29 手工草莓示例图，可直接体验完整流程。

## 说明
屏幕颜色为近似值，实物以瓶身为准。185 色 = 221 色去掉 D26、F25、H5–H23 与 M 系列共 36 色。

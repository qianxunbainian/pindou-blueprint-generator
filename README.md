# 拼豆图纸工坊

照片 → 拼豆图纸：上传一张照片，自动生成带 MARD 色号的拼豆施工图、用豆清单，还能逐色照着拼、导出打印图纸和 3:4 小红书宣传图。全程在浏览器本地处理，照片不上传。

**在线使用：** https://qianxunbainian.github.io/pindou-blueprint-generator/

## 功能

- 5 种转换模式（图标/照片/像素直采等）、最多用色控制、相近色合并
- MARD 221 色卡逐格标注色号，坐标标尺 + 底板辅助线
- 画笔/橡皮/取色编辑，镜像/旋转，智能降噪，替换色号
- 用料统计、购豆清单复制、CSV 导出、稀有色一键精简
- 制作助手：按颜色逐步摆豆，进度可标记
- 导出：色号施工图 PNG、打印、可编辑工程 JSON、3:4 小红书宣传图
- 离线可用（PWA），无账号、无付费

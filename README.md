# 拼豆图纸生成器

照片一键转拼豆图纸：上传照片，自动生成带色号的拼豆图纸 + 用豆清单。

## 功能
- 上传照片（本地处理，不上传服务器，隐私安全）
- 图纸宽度 16–100 格可调，最多颜色 4–40 色可调（颜色越少越省豆）
- 每格显示通用近似色号，可开关网格线 / 色号
- 实时统计：总豆数、实际颜色、成品尺寸（按 5mm 豆）
- 导出高清图纸 PNG（带色号，可打印）
- 导出用豆清单 CSV（色号 + 颗数 + 占比，照着买豆）

## 使用
直接用浏览器打开 `index.html` 即可，无需服务器、无需联网。

## 说明
色号为通用近似色卡编号，不同品牌（MARD / Perler / Hama）请按颜色对照购买。
